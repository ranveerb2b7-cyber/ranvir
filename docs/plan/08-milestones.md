# 8. Development Milestones

Status: **PROPOSAL — awaiting approval.** Each milestone follows the same loop. Before starting: plan → dependencies → limitations → credentials → acceptance tests. After finishing: run tests → fix → verify → update docs → report what is complete and what remains. A milestone is only "done" when its acceptance tests pass in CI.

|---|---|---|---|---|
| **M0** | Planning (this) | Architecture, ERD, API plan, feasibility reports | Your approval | — |
